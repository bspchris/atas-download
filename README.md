# aTAS app download

Download page for the aTAS attendance app (Android). This repository holds only
the released app files; the app's source code is kept elsewhere.

**Latest Android app:** [aTAS.apk](https://github.com/bspchris/atas-download/releases/latest/download/aTAS.apk)

## Install

1. Open the link above on your Android phone and download `aTAS.apk`.
2. Open the downloaded file. If Android asks, allow installs from this source.
3. Open aTAS and sign in with the JET login your admin gave you.
4. Follow the steps on screen to set up your face and PIN.

New versions install over the old one; your sign-in and settings are kept.
iPhone is not supported yet.
